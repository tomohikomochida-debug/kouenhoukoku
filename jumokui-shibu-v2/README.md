# 樹木医会神奈川県支部 支部管理システム v2

第1段階：総務（正本・会員の異動）＋会計（会費台帳・年度追加・送金記録）
第2段階：広報（督促メールの文面・対象・送信）＋総務（本番の送信アカウントの登録・送信記録・郵送リスト）
第3段階：研修（研修会ごとの申込シートとフォーム・参加資格の自動判定・出欠と年度集計）＋総務（長期未納の一覧）

- `コード.gs` … Apps Script に貼り付ける本体（1ファイルのみ）
- `test_logic.js` … 判定・計画部分のテスト
- `test_glue.js` … シート操作部分を模擬環境で通しで動かすテスト

テストの実行：

```
cp コード.gs /tmp/code.js
node test_logic.js /tmp/code.js
node test_glue.js /tmp/code.js
```

スプレッドシート（Google ドライブ「支部管理システム_v2（Claude作成）」フォルダ）

- 総務_正本_v2
- 会計_会費台帳_v2（会費台帳は「会費台帳_2026」など年度ごとのシート）
- 広報_督促_v2
- 研修_申込照合_v2（研修一覧・研修会ごとの「申込_研修ID」・年度ごとの「年度集計_YYYY」・判定の基準）

## 研修の参加資格（支部の運用）

- 会費の年度は開催日で決まる（4月始まり）
- その年度までの会費に、納期限が開催日より前に過ぎた「未納」がある → 参加不可（期限前の未納は参加可）
- 確認中 → 要確認／納入済み・免除・他支部納入済み（本人申告） → 参加可
- 休会 → 参加不可／名簿にない番号・氏名や登録期の不一致 → 要確認／外部（他支部の樹木医・一般） → 判定しない
- 判定は開催日まで自動で更新し、開催後は固定。研修担当の判断で上書きできる
- 2年度分以上の未納（納期限経過）の在籍会員は総務ブック「長期未納」に一覧（退会の手続きは総務が異動受付で行う）
